# hub-de-leitura-teste-ui

## Instalação do sistema que iremos testar

### Pré-requisitos

- Node.js 18+ instalado
- Git instalado
- Visual Studio Code instalado 

### 1. Clone o Repositório e entre na pasta

```bash
git clone https://github.com/EBAC-QE/hub-de-leitura-integrado.git
cd hub-de-leitura-integrado
```

### 2. Instale as Dependências

```bash
npm install
```

### 3. Inicie o Servidor

```bash
npm start
```

## Configurações de ambiente

### Pré-requisitos

- Crie um repositorio no GitHub

### 1. Entre na pasta criada e clone o repositorio

```bash
cd o caminho da pasta que foi criada
git clone o link do repositorio
```
### 2. Instalar as dependências do node

```bash
npm init -y
```

### 3. Instalar o cypress

```bash
npm install cypress@14.5.3
```

### 4. Inicie o cypress

```bash
npx cypress open
```
